Why your draft wins, and how hard it is to play.

OFI Draft Tool reads your champion select from the League client and explains each composition in plain words: the lanes, the power curve, the game plan and what the other team has to do to stop it. A free Windows app, made by and for the OFI Clash team.

What it shows in champion select

  • Both teams, as the client shows them. Picks, bans and your team's hovers. The enemy's roles are not sent by the client, so the app infers them from the visible champions and says so on screen.
  • Lane by lane. Which side is favoured in each lane and by how much gold at 15 minutes, measured on aggregated ranked games, with the sample size next to every number.
  • The game plan of each team. When each composition is strongest, how it wants to fight (engage, peel, poke, split) and what the other side needs to deny it.
  • Options for the next pick and ban. Several candidates, ranked, each with the reason behind it. The decision stays with the player.
  • Runes, summoner spells and an item set for your champion, written to the client only when you press the import button.

Outside champion select it works as a reference: tier lists by rank bracket, a page per champion with builds, rune pages and matchups, and a manual draft board where you can type ten champions to study a composition.

How you use it

  1. Install it.A Windows 10 or 11 installer that does not need administrator rights. It updates itself with versions signed by us, but never while you are in queue, in champion select or in a game.
  2. Open the League client.The app finds it on its own by reading the client's lockfile. It does not touch the game process.
  3. Enter champion select.The analysis refreshes with every pick, ban and hover from your team. The board can sit in its own window next to the client.
  4. Lock in, and import if you want to.Press Import to write the suggested runes, spells and item set to the client. Your current rune page is saved first.

During the game, only if you turn it on

The overlay is optional and can be switched off in the settings. It is a transparent window on top of the game, fed only by Riot's Live Client Data API, the local interface the game itself offers. It never reads the game's memory.

  • Your skill order, with the ability icons.
  • Epic objective timers, from the game's own events.
  • The gold value of each player's items, computed from the items the scoreboard already shows.
  • A short alert about your own team. It never reads the enemy team, never takes focus and never clicks.

It never shows enemy cooldowns, enemy summoner spells, positions or jungle camps.

For the team

  • Players. Each member's roles, champion pool and recent form, measured on their own recent games.
  • Game plans. Compositions the five of you can actually play, with who takes each role and which bans protect the plan.
  • Match history. The team's recent games, with filters by queue, result, role and champion.
  • Clash scouting. Before a Clash match, the opposing roster published by the Clash API and the champions they play.

Where the data comes from

Every statistic comes with its sample size. When there is not enough data, the app says so instead of filling the gap.

Fair play

The tool is built for the time before the game. These rules are part of the code, not a promise added afterwards.

What it does

  • Uses only official Riot interfaces: the Riot API, the League client's local API and the Live Client Data API.
  • Works in champion select and, if you turn the overlay on, during the game.
  • Offers several options with their reasons; the player decides.
  • Writes runes, spells and items only when you press a button.
  • Shows the source and the sample size of every statistic.

What it never does

  • Read or modify the game's memory, inject code or hook into the game.
  • Show enemy cooldowns, enemy summoner spells, positions or jungle camps.
  • Reveal hidden players: enemy names in ranked champion select stay hidden.
  • Act for you: no automatic picks, bans, purchases or level-ups.
  • Rate players with an MMR or elo estimate.
